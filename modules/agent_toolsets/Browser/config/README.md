# Browser Configuration

## English

1. Copy `Browser.json` to your `config` directory.
2. Edit the file and fill in the required parameters: `chrome_path`, `chrome_timeout`.
3. **The tool will not be loaded** without a valid configuration.

## 中文

1. 将 `Browser.json` 复制到 `config` 目录。
2. 编辑文件，填写必需的参数：`chrome_path`, `chrome_timeout`。
3. **配置文件缺失或无效会导致工具无法加载**。
