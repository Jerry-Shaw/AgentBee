# Collaborator Standalone-Configuration

## English

1. Copy `Collaborator.json` to your `config` directory.
2. Edit the file and fill in the required parameters as needed: `org_id`, `api_url`, `api_key`, `model_id`, `timeout`.
3. This configuration file is a standalone configuration file. Even if it is absent, the tool will still load, but it
   will load the default configuration from AgentBee.json.

## 中文

1. 将 `Collaborator.json` 复制到 `config` 目录。
2. 编辑文件，按需填写参数：`org_id`, `api_url`, `api_key`, `model_id`, `timeout`。
3. 该配置文件为独立配置文件，即使没有该配置文件，本工具依然会加载，但会从 AgentBee.json 加载默认配置。
